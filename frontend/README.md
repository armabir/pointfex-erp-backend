# Pointfex ERP — Frontend Prototype

Internal ERP system prototype for a simulated software development company, built with React 19, Vite, Tailwind CSS v4, and Lucide Icons.

## Features

- **Developer Workspace & Dashboard**: Dynamic statistics derived from structured relational mock data, task management overview, active projects progress, upcoming deadlines, recent engineering activity feed, and performance records.
- **Relational Mock Data**: Models covering 6 teams (24 developers), 6 PMs, 4 C-suite executives, 12 projects, tasks, comments, attachments, milestones, and virtual wallet transactions.
- **Interactive State**: Real-time task inspection and status updates, quick task creation, and global search (`⌘K` / `Ctrl+K`).
- **Temporary Role Switcher**: Quick switching between simulated roles (Developer, PM, CTO, CPO, CFO, CEO) with isolated navigation architecture.
- **Modern Minimalist UI**: Clean pastel metric cards, pill navigation, and soft aesthetic designed for comfortable, low-fatigue engineering sessions.

## Tech Stack

- **React 19**
- **Vite 8**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Lucide React**

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
